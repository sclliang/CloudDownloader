# CloudDownloader 0.4.3 验证记录

验证日期：2026-10-18。环境：Windows x64、Edge/WebView2。
淡紫色主题与 0.4.2 的验证记录保存在 docs/verification-0.4.2.md。

## 本次修改

- 删除下载任务的确认框新增「同时删除本地文件」，每次打开默认不勾选，显示任务名称与保存目录。
- 未勾选时保留下载文件和续传信息；勾选后明确提示永久删除，并清理当前任务文件及对应 .aria2 文件。
- 先等待下载引擎释放该任务，再清理本地文件。停止失败、文件被占用或文件清理失败时保留记录并显示错误，支持重试。
- 只清理当前任务的普通文件，拒绝异常文件名、目录、符号链接或重解析点，以及其他任务仍使用的文件，不递归删除下载目录。
- 上传记录的行为保持不变：保留本地源文件和网盘文件。

## 界面与发布包验证

- 从 package/CloudDownloader.exe 启动正式 0.4.3，使用仅包含 Windows 系统目录的 PATH，并从其他工作目录启动；下载引擎正常就绪。
- 使用本机 HTTP 服务生成一个独有文件名的 2.9 KiB 合成文件，并通过普通下载表单完成下载。实际确认框默认未勾选「同时删除本地文件」，按钮显示「仅移除任务」；勾选后显示永久删除提示，按钮切换为「删除任务及文件」。
- 界面验证后取消确认框，停止验证实例，仅清理匹配合成文件名和本机来源 URL 的测试文件与记录，原有用户文件和记录未做删除。
- 最终产物位于 package/CloudDownloader.exe，依赖保持 package/bin/ 布局。EXE 属性核对通过：sixunited、sclliang 作者版权、CloudDownloader 产品及内部名称、CloudDownloader.exe 原始文件名、英文功能说明、英语（美国）资源，以及一致的数字和字符串版本 0.4.3.0。
