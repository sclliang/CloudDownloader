# CloudDownloader 0.5.5 验证记录

验证日期：2026-10-18，Asia/Shanghai。历史记录见 docs/verification-0.5.4.md。

发布状态：按用户要求暂停上传 GitHub 和 Release。

## 本次修改

- 新增标题栏主题按钮，位于最小化按钮左侧，在淡紫色日间与 Night 主题之间切换。
- 使用本机 WebView localStorage 保存主题选择，启动前恢复页面配色，并同步原生窗口主题与背景色。
- 自定义标题栏保留拖动、双击最大化、最小化、最大化／还原和关闭到托盘。窗口操作权限仅授予主窗口。
- Night 主题覆盖文件列表、任务、输入、状态提示与弹窗，保持列表底部操作区可见。
- 参考 CYQawa/YunX 的 0a7c71eab81ba25727106fda213165f621621048 版本，新增 UC、蓝奏云、蓝奏云优享版的独立官方登录、个人目录分页及分享下载流程。没有接收或保存账号密码。
- UC 区分个人下载和分享通道、对应 UA、Origin/Referer，并传递 API 生成的有限下载 Cookie；原样保留 Cookie 编码，不发送其他账号字段到下载节点。
- 普通蓝奏读取 uid/vei、目录和文件分页、已有外链信息，解析分享 HTML、同源 iframe 和下载参数，支持提取码；取链检查实际字节长度及验证页。
- 优享版复用官方网页 appToken Cookie，保存设备标识，按协议加密 timestamp/auth/downloadId，支持 API 302 和 JSON 下载地址；保留 appToken 特殊编码。
