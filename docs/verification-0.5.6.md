# CloudDownloader 0.5.6 验证记录

验证日期：2026-10-18，Asia/Shanghai。历史记录见 docs/verification-0.5.5.md 和 docs/verification-0.5.4.md。

发布版本：[v0.5.6](https://github.com/sclliang/CloudDownloader/releases/tag/v0.5.6)，同步对应源码、Windows 安装包、便携版与 SHA-256 校验文件，仓库保持 public。

## 本次修改

- 新建下载改为统一输入框，移除普通链接／网盘分享的手动切换和旧独立表单。后端自动分类，网盘解析失败不会作为普通文件下载 HTML 页面。
- 支持普通 HTTP/HTTPS、八网盘分享、BT v1 磁力链接、HTTP/HTTPS 种子地址及本地种子导入。仅显示预览时不创建文件传输任务。
- 磁力解析使用 aria2 metadata-only，返回可取消的解析任务，约三分钟超时；完成后验证原始 info 字节的 SHA-1，缓存元数据用于续传。
- 严格解析种子结构、分片数量、路径及文件清单；限制 4 MiB 和 10000 个文件，拒绝纯 v2、不兼容编码、目录穿越、Windows 设备名、重复路径、大小写冲突、文件与目录冲突及符号链接。
- BT 任务独立目录，写入归属标记；下载开始前在暂停状态核对 aria2 返回的哈希、文件序号、路径与大小，再允许传输。
- BT 默认 64 个节点、512 KiB/s 上传上限，默认完成后停止，可选择做种。BT 连接独立于 HTTP 每服务器最多 16 路连接。
- 支持选文件、暂停、引擎重启后续传，按所选文件与验证分片计算进度，避免 aria2 1.37 多文件选择下载的 completedLength 少计问题。
- 删除 BT 文件前停止任务并校验目录归属，按完整清单清理分片可能触及的相邻文件；拒绝重解析点及跨任务重叠，额外用户文件和原始种子保留。

- 本地 Tracker + 两个真实 aria2 1.37 引擎：磁力元数据获取成功，确认前未创建 payload 目录；多文件种子仅选第二个文件，实际暂停并重启下载引擎后成功续传，所选文件逐字节一致；未选择文件只有跨界分片有效数据，其他位置为空洞。配置继续做种后保持活动状态，暂停与停止成功。
- 链接分类额外验证保留普通 URL 与磁力参数中的合法括号，并正确提取 Markdown 链接。

## 验证范围

BT 验证使用本机合成数据和本地 Tracker，未下载公网资源，公网 Tracker、DHT 可用性及速度仍取决于实际网络和在线节点。支持 v1/混合种子，暂不支持纯 v2；非 UTF-8 或不符合 Windows 路径规则的种子会明确拒绝。

UC、蓝奏云、优享版本轮没有真实账号或分享下载实测，保留上一版本的模拟协议验证结论。原有五网盘的实际验证记录沿用历史文档，不扩大通过范围。
