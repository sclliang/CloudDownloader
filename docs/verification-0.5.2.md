# CloudDownloader 0.5.2 验证记录

验证日期：2026-10-18，Asia/Shanghai。历史版本记录见 docs/verification-0.5.1.md。

## 修复内容

- 115 原先仅依赖 WebView2 资料目录，浏览器的会话型 Cookie 在退出后可能丢失。现在使用当前 Windows 用户的 DPAPI 加密保存 115 登录 Cookie，并在官方页面加载前恢复；保留原始过期时间、Secure、HttpOnly、SameSite 与会话属性。
- 正常退出前在后台线程再次保存最新 115 会话，避免在 UI 线程读取 Cookie 导致退出卡住。网页登录退出、缺少必要登录字段时清除该缓存；资料损坏或无法解密时仍可进入官方页面重新登录。
- Cookie 恢复保留 115 主域和 API 子域的适用范围；下载请求保留登录 Cookie 的原始编码，并补齐客户端可能需要的登录字段。登录字段只限于 115 域名下的指定名称，不写入任务记录。
- 夸克、百度、115、123、139 的分享与个人网盘下载统一从每文件最多 4 路调整为最多 16 路，最小分段从 4 MiB 降为 1 MiB；最多同时下载 3 个文件。普通直链仍按用户选择的连接数下载。

## 已执行验证

- Rust 回归测试 45 项通过、0 项失败、1 项需要用户提供真实分享的测试跳过。
- 使用真实 aria2 和本地 HTTP Range 服务验证通用网盘下载入口：实际参数为 split=16、max-connection-per-server=16、min-split-size=1 MiB；实测并发请求超过 4 路，下载内容逐字节一致。直接下载的连接数选择、非分段回退、引擎重启续传及停止后文件删除测试也通过。
- DPAPI 测试覆盖加密文件中不包含测试明文、重读与原子更新、篡改拒绝、过期 Cookie 和外域 Cookie 过滤、网页登录退出清理；下载请求测试确认保留百分号编码并排除其他 Cookie。
- 两个独立原生进程使用各自全新的隔离 WebView2 资料目录：首个进程保存加密的模拟会话后退出，第二个进程成功解密并恢复 Cookie。主站与 API 子域各读取到 2 个测试 Cookie，HttpOnly 与会话属性保持一致。没有访问 115 页面，也没有使用真实账号或登录资料。
- TypeScript 类型检查和 Vite 发布构建通过；本次涉及的前端文件、版本配置通过 Prettier 检查。Rust 格式检查通过。

更新后请在 115 官方窗口登录一次以建立加密缓存，再通过托盘退出并重启验证真实账号。跨进程验证使用模拟会话，真实 115 登录保持与各网盘下载速度仍需用户实测。实际连接数受文件大小、HTTP Range 支持及服务器调度影响；速度、会员权限、额度和限流仍由服务端及网络决定。
