# CloudDownloader 0.5.3 验证记录

验证日期：2026-10-18，Asia/Shanghai。历史记录见 docs/verification-0.5.2.md。

## 本次调整

- 为 115 登录窗口初始化增加同步保护。同一网盘的账号检查、打开窗口、目录请求等并发调用，必须等待加密 Cookie 恢复与首次导航提交完成，才能取得窗口并读取会话；避免读取尚未恢复的空会话并影响缓存。
- 115 错误码 990001 单独显示为登录会话无效，明确要求在官方窗口重新登录后刷新，不再混用提取码、会员权限等通用提示。
- 新增仅限开发构建的 115 会话诊断入口，同时建立三个会话并执行只读账号校验；报告只包含 Cookie 名称、属性、数量和认证是否成功，不导出值、账号标识或昵称。

## 实际观察与验证

- 排查开始时，当前用户资料目录中没有 115 加密缓存，程序报告 990001。用户在官方窗口手动重新登录后，程序生成包含 7 个登录字段的加密缓存；独立只读请求确认该缓存能通过 115 官方账号接口验证。
- 重新登录后，0.5.2 单次恢复与并发恢复均成功，未直接重现用户原截图的失败；因此本次同步保护是对代码中初始化时序风险的修复，不能据此断言它是原故障的唯一原因。
- 使用用户本轮已登录的真实 115 会话完成重启校验。用户随后再次退出正式版，退出后的加密缓存仍能通过官方账号接口认证。
- 0.5.3 连续启动两个独立原生进程；每个进程同步发起三个 115 会话请求，3/3 均通过官方账号接口，7 个登录字段均保持。进程通过程序正常退出流程结束；每轮退出后再次读取加密缓存，认证均成功。没有再次扫码、提交凭据或修改网盘文件。
- Rust 回归 46 项通过、0 项失败、1 项需要真实分享链接的测试跳过。新增 990001 提示测试通过；已有加密存储、篡改拒绝、注销清理、16 路下载、续传和任务删除测试通过。
- TypeScript 类型检查、Vite 发布构建、Rust 格式检查和本次版本配置的 Prettier 检查通过。
