# CloudDownloader 0.5.1 验证记录

验证日期：2026-10-18，Asia/Shanghai。历史版本记录见 docs/verification-0.5.0.md。

## 修复内容

- 139 部分系统文件夹的 fileId 以 / 开头。旧版使用其他网盘的普通 ID 校验，因拒绝这种合法标识而导致目录加载和登录状态检查失败。
- 为 139 保留原始网盘 ID，内部路径将其前导斜杠编码为 %2F；进入目录、恢复任务和请求下载地址时还原原始 ID。其他网盘保持原有校验，继续拒绝路径穿越和异常字符。
- 139 账号状态校验与文件条目解析分开，避免单条目录元数据影响已登录状态。
- 123 登录窗口改为 https://yun.123pan.cn/，由官方页面跳转至 user.123pan.cn/centerlogin；此前的 www.123pan.com 是宣传主页。
- 登录状态从未连接变为已连接时，个人网盘页面自动重新加载文件。正在请求时等待当前操作结束后刷新。

- TypeScript 类型检查、Prettier 和 Rust 格式检查通过；Vite 发布构建通过。
