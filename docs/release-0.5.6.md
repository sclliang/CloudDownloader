# CloudDownloader 0.5.6

统一下载入口，新增 BT 磁力与种子下载、Night 主题，以及 UC、蓝奏云和蓝奏云优享版。

- 下载入口合并为一个输入框，自动识别 HTTP/HTTPS 文件、八网盘分享、magnet 磁力链接及 HTTP/HTTPS 种子地址，支持导入本地 `.torrent`。
- 所有来源先显示文件预览，确认后开始下载；网盘可进入子目录，BT 可选择部分文件。取消解析或修改链接后，旧解析结果不会创建下载任务。
- BT 支持 v1 和混合种子；磁力元数据解析阶段不下载文件内容。支持暂停、重启续传、每任务节点数和上传限速，以及完成后可选做种。
- BT 默认最多 64 个节点，可设 1–500；普通链接默认最多 16 路连接。BT 进度根据所选文件与已校验分片计算，任务显示节点数与上传速度。
- 每个种子使用独立目录。移除任务默认保留文件，勾选删除时按文件清单清理，保留额外文件和原始种子，拒绝链接目录及与其他任务重叠的文件。
- 最小化按钮左侧新增淡紫色／Night 主题切换，自动保存选择；新增 UC、蓝奏云、蓝奏云优享版的官方登录、分享解析和个人网盘下载入口，个人网盘底部操作区保持可见。

安装包：`CloudDownloader_0.5.6_x64-setup.exe`；便携版：`CloudDownloader-0.5.6-win-x64.zip`。需 Windows 10/11 x64 和 WebView2。校验值见 `SHA256SUMS-0.5.6.txt`。

BT 已通过本地 Tracker 和真实 aria2 节点的磁力解析、文件选择、暂停和引擎重启续传验证。实际公网 BT 速度取决于节点与网络；纯 BT v2 暂不支持。新增三网盘的真实账号与传输仍待用户验证，详情见 `VERIFICATION.md`。
