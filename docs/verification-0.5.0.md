# CloudDownloader 0.5.0 验证记录

验证日期：2026-10-18。环境：Windows x64、Edge/WebView2。
主题改动记录见 docs/verification-0.4.2.md；可选删除本地文件的记录见 docs/verification-0.4.3.md。

## 本次修改

- 新增 115、123、139 分享链接解析、提取码识别、目录浏览、文件和文件夹下载。
- 「我的网盘」加入五个网盘切换；新增夸克、115、123、139 个人文件浏览、分页加载、文件筛选及批量下载。
- 复用下载队列、暂停续传、错误重试、同名编号和可选本地文件清理。
- 五个网盘独立官方登录窗口；123 令牌从其登录窗口读取、139 读取对应网页登录状态，登录资料不经过主界面或任务数据库。
- 恢复个人下载时核对账号、文件大小与可用校验信息；临时下载地址只用于当次传输。123 的随机设备 UUID 保存在本机设置中。
- 115 使用 RSA/XOR 客户端取链和临时对象 Cookie，123 使用 CRC32 签名，139 使用 MD5 签名及 AES-CBC 分享请求。123、139 的 CDN 请求不携带账号令牌或 Cookie；115 的下载会带对应登录及对象 Cookie。
- 维持淡紫色主题和百度原有上传、分享功能。

## 自动验证

以下结果在发布构建前执行并记录：

- TypeScript 类型检查、前端构建、Prettier 和 Rust 格式检查通过。
- Rust 完整回归 39 项通过、0 项失败、1 项真实分享测试跳过；包含真实本地 HTTP 与 aria2 的多连接下载、暂停续传、引擎重启、任务停止与文件清理。
- 通过独立 Python CRC32、MD5、RSA 和 AES 计算生成固定协议向量，验证 115 单块及多块加密、123 签名、139 Unicode 签名、AES 及 gzip 响应解密和无效密文处理。
- 本地模拟 HTTP 接口验证夸克、123、139 的个人文件下载取链流程，以及 115 分享列表和账号识别、123 空分页游标、139 匿名加密分享列表。
- 验证账号切换会在获取下载链接前停止，元数据不序列化临时令牌，错误信息不包含模拟服务端返回的凭据，拒绝伪造分享域名和跨网盘下载域名。

这些模拟响应使用合成数据，不是网盘真实返回值的录制。测试环境的本地接口替换仅编译进 Rust 测试，正式程序无法启用。

## 发布包验证

正式产物为 package/CloudDownloader.exe，下载引擎位于 package/bin/aria2c.exe，许可资料位于 package/bin/notices/。
已从其他工作目录、仅含 Windows 系统目录的 PATH 启动正式发布包，界面及 package/bin/aria2c.exe 下载引擎正常运行；主程序及引擎的 PE 导入表均为 Windows 系统 DLL，未引用开发工具 DLL。

原生窗口确认显示 v0.5.0、淡紫色主题、五个个人网盘入口及五个分享来源提示。复用本机原有夸克登录状态，真实个人根目录成功加载 6 项；未新建真实云盘文件下载任务。

EXE 属性检查通过：sixunited、sclliang 作者版权、CloudDownloader 名称、CloudDownloader.exe 原始文件名、英文功能说明、英语（美国）资源，以及一致的数字和字符串版本 0.5.0.0。

## 待用户验证

按用户要求，不要求提供账号或测试分享链接，本次未验证 115、123、139 真实登录、个人目录、分享解析及文件传输，也未验证新增夸克个人下载的真实取链与传输。真实服务端可能因会员权限、流量额度、验证码、区域或接口变化拒绝请求。

建议逐一验证：官方窗口登录后刷新；浏览至少一个子文件夹及下一页；下载一个个人文件和一个分享文件；选择文件夹；暂停后继续；重启后恢复；切换账号后确认旧账号任务被阻止继续。如遇问题，可提供网盘名称和界面错误码，避免提供密码、Cookie、令牌或完整的临时下载地址。
