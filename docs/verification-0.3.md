# CloudDownloader 0.3.0 验证记录

验证日期：2026-10-02。环境：Windows x64，当前机器已登录的百度和夸克账号。

本版本新增百度个人网盘浏览、下载、分片上传和分享管理，复用原有官方网页登录资料。原百度与夸克分享下载保留；未增加阿里或天翼支持。历史版本证据见 `docs/verification-0.2.md` 和 `docs/verification-0.1.md`。

## 实际百度接口验证

- 原登录状态可直接读取百度个人网盘根目录，无需重新登录或开放平台授权。
- 新建专用验证目录，上传程序生成的二进制文件；文件大小为 26,214,533 字节，拆为 7 个分片，每文件并发设为 4。
- 第一次实际运行在确认 4 个分片后暂停，退出应用，再次启动后恢复上传成功。
- 第二次独立文件在确认 3 个分片（12,582,912 字节）后暂停并退出。重启后的预创建请求复用同一上传会话，服务端报告还缺少 3 片：暂停时另一个在途分片已被服务端收到。
- 第二次全程客户端记录 6 次分片成功确认，另 1 片由恢复时查询服务端确认。恢复没有重新发送暂停前已确认的分片。
- 上传完成后，通过个人文件下载地址完整取回，逐字节比较与本地源文件一致。
- 同一文件通过正常「我的网盘 → 下载任务 → aria2」路径下载完成，再次逐字节比较一致。
- 创建带提取码、1 天有效的分享，分享列表能够读取生成的文件；随后通过取消接口成功取消，并保存本地取消状态。两次测试分享均已取消。
- 中文名称的空文件（0 字节）和文本文件（29 字节）同时上传成功。
- 搜索能够返回验证文件；传入不同账号标识时，账号绑定检查拒绝继续操作。
- 同名上传在加入队列前被拒绝。另用生成的小文件验证最终提交接口的 `rtype=0` 冲突保护，服务端拒绝替换，原文件大小保持不变。

真实账号验证使用开发构建中显式启用的验证程序；Release 构建不包含该入口。验证记录只包含结果、大小、计数和生成的文件路径，不导出 Cookie、下载地址签名或账号令牌。

本次仅上传程序生成的验证文件，保留在网盘的两个 `CloudDownloader-验证-*` 目录中，合计约 50 MiB。测试未删除既有文件，未自动清理验证目录。

- `npm run build`：TypeScript 检查和 Vite 生产构建通过。

## 验证边界

- 实际上传使用 25 MiB 级文件、空文件和小文本，未做数 GB 文件的持续压力测试，也未将并发数与具体倍速作等同保证。
- 未等待百度上传会话自然过期；到期后的行为依据错误处理逻辑，需重试并重新上传。
- 未用超过 100 项的真实目录验证分页边界，也未现场测试 1 天之外的分享有效期；请求参数支持 1、7、30 天。
- 上传速度和权限由网络及百度服务端决定。网页接口发生变化时可能需要更新适配。
- 分享记录仅保存本程序创建的分享，外部客户端取消或修改的状态不自动同步。
