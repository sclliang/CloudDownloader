# CloudDownloader 0.5.5

本地待发布版本；当前暂停 GitHub 发布。

新增淡紫色日间／Night 主题切换，以及 UC、蓝奏云、蓝奏云优享版下载。

- 参考 CYQawa/YunX 接入三个新增网盘的分享解析、官方网页登录及个人文件下载，账号分别保存在独立资料目录。
- UC 区分分享与个人网盘下载通道，普通蓝奏支持文件夹及提取码，优享版支持设备标识与下载参数加密。
- 在窗口右上角、最小化按钮左侧增加月亮／太阳按钮，点击即可切换主题。
- 自动保存主题选择，重新启动程序后恢复。
- Night 配色覆盖导航、个人网盘、下载与上传任务、分享记录、输入框和弹窗。
- 标题栏支持拖动、双击最大化、最小化、最大化和还原；关闭按钮继续收进托盘。
- 保留个人网盘列表内部滚动及底部下载、分享按钮和保存目录完整显示。

下载 `CloudDownloader_0.5.5_x64-setup.exe` 安装版，或解压 `CloudDownloader-0.5.5-win-x64.zip` 使用便携版。支持 Windows 10/11 x64，升级保留账号资料和任务。校验值见 `SHA256SUMS-0.5.5.txt`。

三个新增网盘的真实账号和下载尚待用户验证，已完成本地模拟协议检查。完整验证范围见 `VERIFICATION.md`。
