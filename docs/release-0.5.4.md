# CloudDownloader 0.5.4

新增 Windows x64 中文安装包，支持安装、升级、快捷方式和卸载；同时提供便携版 ZIP。

## 更新内容

- 使用淡紫色主题，移除原鸣潮主题、立绘和角色切换。
- 修复个人网盘页面底部操作区被截断：文件列表随可用高度内部滚动，下载、分享按钮和保存目录保持可见。
- 接入 115、123、139 的分享及个人网盘下载，增加夸克个人网盘下载；保留百度下载、上传和分享功能。
- 五个网盘下载统一支持每文件最多 16 路连接，最小分段 1 MiB；实际连接数及速度受文件大小、服务器和网络影响。
- 删除下载任务时可选择同时删除本地文件，默认只移除任务并保留文件。
- 修复 139 登录识别及系统文件夹 ID，更新 123 官方登录入口。
- 115 登录资料使用当前 Windows 用户加密保存，重启时恢复；增加初始化等待和明确的会话失效提示。
- 主程序位于安装目录根部，下载引擎和许可资料统一放在 `bin/`，支持从其他工作目录启动。

## 下载与安装

- `CloudDownloader_0.5.4_x64-setup.exe`：推荐安装版，中文界面，默认安装到当前用户目录。
- `CloudDownloader-0.5.4-win-x64.zip`：便携版，解压后运行 `CloudDownloader.exe`，保留整个目录结构。
- `SHA256SUMS-0.5.4.txt`：上述两个文件的 SHA-256 校验值。

支持 Windows 10/11 x64。缺少 WebView2 时，安装包会联网从微软下载运行时。升级保留原任务与账号资料；卸载默认保留应用数据，主动勾选清除时才删除。下载文件位于用户选择的保存目录。

已完成本地协议回归及 115 当前真实账号退出重启验证。115、123、139 的各类分享、会员权限和实际传输仍需结合自己的账号验证；软件不保证突破网盘服务端限速。详细验证记录见仓库 `VERIFICATION.md`。
